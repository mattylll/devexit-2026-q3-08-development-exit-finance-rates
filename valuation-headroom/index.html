How much valuation headroom is left?

A lower valuation can create a cash gap even while the redemption-to-value ratio stays below an assumed gross lending cap.

This is the accessible companion to our three-page valuation guide. The development exit refinance guide at DevExit.co.uk explains the funding route. Here, original fictional arithmetic tests whether the net proceeds would cover redemption.

£42,500 of net headroomIn the fictional starting case, a 5% valuation fall turns this into a £37,125 completion gap.

Start with net proceeds

Assume an accepted value of £2.5 million, a 65% gross cap, a fee of 2% of gross finance, £50,000 of other completion deductions and £1.5 million needed to redeem existing debt. These inputs are invented; the cap and fee are not quoted lender terms.

The gross cap is £1,625,000. Subtract the £32,500 fee and £50,000 other deductions to leave £1,542,500. After redemption, £42,500 remains. The £125,000 difference between gross finance and redemption is not spendable cash.

The net-advance calculator explores deductions separately. In this guide, the fee percentage and other deductions stay fixed so we can isolate the effect of valuation. Interest is serviced separately; no retained or rolled interest is deducted here.

At £2.375 million, redemption divided by value is 63.16%, below the assumed 65% gross cap. Yet the net advance is £37,125 short. Passing the gross comparison does not establish that completion is funded.

Find the value at which the cash just covers redemption

Net proceeds = value × 0.65 × (1 - 0.02) - £50,000
Required value = (£1,500,000 + £50,000) ÷ (0.65 × 0.98)
Required value = £2,433,281.00, rounded to the nearest penny.

That is only about 2.67% below the starting valuation. It contains no buffer. This is a replacement-funding threshold, not an existing-loan covenant test or a valuation opinion. A different fee basis, interest reserve, income limit or facility cap changes the result.

Keep the other checks visible

Value basis. Record the assets covered, valuation date, basis and acceptance status. An asking-price total, future GDV or portfolio value is not automatically the relevant security value.

Completion cash. Use a current redemption statement and itemise each deduction once. If the result is short, record the cash source, availability date and any restrictions.

Operating cash. A fully funded redemption can still leave a later shortage. The cash-buffer notebook checks outgoings before retained sale receipts arrive.

Time to complete. The refinance-start timetable works backwards through preparation and completion dependencies. If retaining and letting the units is the fallback, use the rental fallback funding test to examine the income limit too.

Record the accepted value, net proceeds, redemption, cash gap, evidence date, action and owner together. The DevExit research and tools guide connects these checks to the rest of the exit plan.
