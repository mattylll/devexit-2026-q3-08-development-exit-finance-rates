# DevExit final-unit release calculator

By Matt Lenzie for DevExit. DX-06, 6 November 2026.

An illustrative calculator comparing principal releases with a net-proceeds sweep, remaining gross security ratios, cash retained and interest over a subsequent no-sale period. All inputs are hypothetical, not calibrated lender terms. See the in-app method and exclusions.
